Artifact 1 · Setup guide · Audience: classmates starting Python

Setting up Python and checking that it works

IWU · Object-oriented Programming · October 16, 2026

What I did

I downloaded Python from python.org, installed Jupyter Notebook, and ran print('Hello, world!') to confirm everything worked. I also ran a script in VS Code from PowerShell to check the active Python version.

import sys

print("Hello world , Python is working perfectly in VS Code!")
print(f"Active Python Version: {sys.version}")

What I learned

Python ran my first script in one line. In Java I had to write boilerplate and compile first. Jupyter's cell-based layout lets me write code, run it and see the result right away, which suits learning, testing ideas and data analysis.

Choosing the right tools matters as much as writing the program, and a good IDE makes programming faster. This also showed me why Python is so popular in data science and analytics.

Why it matters for my work

I can now compare Python and Java syntax first-hand, which helps with my group project that runs side by side in both languages.

Artifact 2 · Setup guide · Audience: hiring managers and instructors

Installing the Java SE SDK and an IDE

IWU · Object-oriented Programming · September 2, 2026

Java SDK
JDK 26.0.1 (HotSpot 64-bit)
IDE
Visual Studio Code
Test program
Welcome1.java

Step 1: Install the JDK and verify it

After installing the JDK I ran both version commands in Command Prompt. java -version reports the runtime and javac -version reports the compiler. Both returned 26.0.1, so the runtime and compiler match.

Step 2: Install the IDE

I installed Visual Studio Code, which is where I write and run my Java code.

Step 3: Write and run Welcome1.java

I wrote a short class that prints three lines, then ran it from VS Code. The terminal output confirmed the JDK and IDE work together.
